# LUMÉ Beauty Studio

Bu proje Lovable ile bağlantılı bir Next.js uygulamasıdır.

## Geliştirme

Node.js ve Yarn gereklidir.

```sh
yarn install
yarn dev
```

Üretim derlemesi için:

```sh
yarn build
yarn start
```

## Teknolojiler

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Yerel mock veriler
